Telegram-бот для управления задачами и формирования полезных привычек, созданный на Python с использованием библиотеки python-telegram-bot. Бот помогает школьникам и студентам организовывать ежедневные дела через простой интерфейс с интерактивными кнопками, ведёт учёт выполненных задач и отслеживает прогресс в развитии привычек с помощью системы счётчиков (streak). Проект использует SQLite для хранения данных и предоставляет функции добавления, удаления и отметки выполнения задач, а также просмотра статистики. Бот готов к использованию и имеет потенциал для дальнейшего расширения функционала.
